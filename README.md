# 選股雷達：Minervini 趨勢 × Buffett 價值

輸入股票代號，自動結合 Mark Minervini（趨勢、時機）與 Warren Buffett（公司體質、價格）的方法，給出**一個綜合建議**。台股與美股都可以用。

- **選股**：強力買進／買進／觀察／避開
- **我的持股**：賣出／減碼／續抱／加碼（只需要輸入代號，不用填成本或日期）

## 安裝與執行

```bash
pip install -r requirements.txt
python app.py
```

開啟 <http://127.0.0.1:5057>。Windows 也可以直接雙擊 `start.bat`。

## 使用方式

1. **選股**分頁：輸入代號按「加入」，或從「一次加入一組」選台股權值股／美股科技股／巴菲特持股。台股輸入數字即可（例如 `2330`，上市／上櫃自動判斷），美股輸入英文代號（例如 `AAPL`）。
2. **我的持股**分頁：輸入你持有的股票代號，就會顯示該賣出、減碼、續抱或加碼，以及理由。
3. 點任一檔股票可看股價走勢圖與詳細條件。
4. 網頁會自動定時更新；按「🔔 通知」後，持股建議改變時會跳出通知。

## 判斷方式

| 面向 | 看什麼 |
| --- | --- |
| 趨勢面（Minervini） | 50／150／200 日均線、52 週高低點、相對大盤強弱、是否帶量突破近期高點 |
| 基本面（Buffett） | ROE、毛利率、淨利率、負債比、自由現金流、獲利穩定成長、現金流折現估算內在價值 |

兩者都好 → 強力買進；趨勢破壞且公司不夠優質 → 賣出；優質企業趨勢轉壞 → 先減碼。完整規則見網頁的「說明」分頁與 `analysis.py`。

觀察清單與持股存在你自己的瀏覽器裡（舊版的 `data.json` 會在第一次開啟時自動帶入）。

## 限制

- 資料來自 Yahoo Finance（yfinance），股價約延遲 15–20 分鐘；財報每 12 小時更新
- 內在價值估算對成長率假設敏感，僅供參考

> 本工具依公開規則自動計算，不構成投資建議。
